## Introduction

This is a sample blog post to show you how to structure your original content on your portfolio site. You can write about your research, experiments, learnings, and technical deep-dives here.

## How to Write a Blog Post

### 1. Create a new file in `src/content/blog/`

Name it something descriptive: `my-blog-post.md`

### 2. Add frontmatter at the top

```yaml
---
title: "Your Blog Title"
date: 2025-01-30
description: "Brief description for previews"
tags: ["Tag1", "Tag2", "Tag3"]
draft: false
---
```

### 3. Write in Markdown

Everything below the frontmatter is your actual blog content. Use standard Markdown:

- **Bold text**: `**bold**`
- *Italic text*: `*italic*`
- [Links](https://example.com): `[text](url)`
- `Code`: wrap in backticks
- Code blocks with language:

```python
def hello_world():
    print("Hello, World!")
```

## Sections and Headers

## Tips

- Set `draft: true` to hide a post while working on it
- Use meaningful dates for sorting
- Add relevant tags for categorization
- Keep descriptions under 160 characters for better previews
